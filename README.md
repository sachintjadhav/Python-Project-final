**Restaurant Management & Billing System**

**📌 Project Overview**

Restaurant Management & Billing System is a Python-based console application designed to manage essential restaurant operations such as menu management, customer order processing, automated billing, order history, and sales reporting.
The project uses Python, JSON file handling, functions, data structures, exception handling, and datetime operations to create a simple and practical restaurant management solution.
The application provides separate options for customers and administrators, allowing menu items to be managed and customer orders to be processed efficiently.


________________________________________
**🎯 Project Objective**

The main objective of this project is to develop a simple restaurant management application that can:
•	Manage restaurant menu items and prices.
•	Allow customers to place orders.
•	Calculate item-wise totals, subtotal, GST, and grand total.
•	Generate detailed customer bills.
•	Store menu and order information using JSON files.
•	Maintain order history.
•	Search previous orders using Order ID.
•	Generate basic sales reports.
•	Provide an admin panel for menu management.
________________________________________


**🚀 Key Features**

**1. Menu Management**
The system provides an admin panel for managing restaurant menu items.
Administrators can:
•	View menu items
•	Add new food items
•	Update existing food items
•	Delete menu items
•	Update item prices
________________________________________
**2. Customer Order Management**
Customers can:
•	View available menu items.
•	Select food items using Item ID.
•	Enter required quantities.
•	Add multiple items to an order.
•	Receive validation for invalid item IDs and quantities.
________________________________________
**3. Automated Billing**
The system automatically calculates:
Item Total = Price × Quantity

Subtotal = Sum of Item Totals

GST = Subtotal × 5%

Grand Total = Subtotal + GST
The generated bill contains:
•	Order ID
•	Customer name
•	Date
•	Time
•	Ordered items
•	Quantity
•	Item price
•	Item total
•	Subtotal
•	GST
•	Grand total
________________________________________
**4. Order History**
All completed orders are stored in a JSON file.
The application allows users to view:
•	Previous Order IDs
•	Customer names
•	Order dates
•	Order times
•	Ordered items
•	Quantities
•	Grand totals
________________________________________
**5. Order Search**
Users can search for a specific order by entering its Order ID.
The system retrieves the corresponding order and displays its complete bill.
________________________________________
**6. Sales Report**
The application provides a basic sales reporting feature that calculates:
•	Total Orders
•	Total Items Sold
•	Total Sales
•	Average Order Value
This feature demonstrates how transaction data can be converted into useful business metrics.
________________________________________
**7. Data Persistence**
The project uses JSON files to store application data:
menu.json
orders.json
This allows menu and order information to remain available after the application is closed and restarted.
